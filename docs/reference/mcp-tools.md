# MCP tool contracts

> Generated by `system tools --markdown` from a running profile (`tools/list`), so it shows
> exactly what clients see; regenerate after changing a tool.

## `account_code`

Operator tool: supply the one-time code a running sign-in is waiting for.

Scope: `operator`

| Argument | Type | Required | Description |
|---|---|---|---|
| `account` | string | yes |  |
| `code` | string | yes |  |

## `account_list`

List provider accounts and their status (no secrets).

Scope: `operator`

No arguments.

## `account_login`

Open a remote login desktop for an account (noVNC over an SSH tunnel). Returns the URL and the ssh -L command; the operator signs in and presses Save account.

Scope: `operator`

| Argument | Type | Required | Description |
|---|---|---|---|
| `account` | string | yes |  |

## `account_probe`

Prove which website features an account offers now (Deep research, Web search, ...), read from the site without sending anything; routing uses only proven features.

Scope: `operator`

| Argument | Type | Required | Description |
|---|---|---|---|
| `account` | string | yes |  |

## `account_relogin`

Operator tool: sign an account in again with its stored credentials (local TOTP; an emailed code is supplied with account_code).

Scope: `operator`

| Argument | Type | Required | Description |
|---|---|---|---|
| `account` | string | yes |  |

## `account_save`

Save an account after an interactive login: capture its login profile, verify, and store it encrypted.

| Argument | Type | Required | Description |

| `account` | string | yes |  |

## `approve`

Approve or reject the plan a run is waiting on (an operator decision, bound to that exact plan).

Scope: `operator`

| Argument | Type | Required | Description |
|---|---|---|---|
| `runId` | string | yes |  |
| `verdict` | "approved" \| "rejected" | yes |  |
| `note` | string |  |  |
| `plan` | string |  | The plan artifact you read; required when several plans wait |

## `ask`

Ask one Worker, chosen by the router for the work (capability, tier, quota order). Waits up to waitSeconds; otherwise returns a runId for `result`.

Scope: `client`

| Argument | Type | Required | Description |
|---|---|---|---|
| `prompt` | string | yes |  |
| `sessionId` | string |  | Continue an existing persistent session |
| `persist` | boolean |  | Start a persistent session (a normal conversation) |
| `tier` | "economy" \| "standard" \| "frontier" |  | Minimum intelligence tier; the lowest admitted tier at or above it runs |
| `classification` | "public" \| "operator-shared" \| "local-private" |  | Data classification of the input; local-private content never leaves the machine (INV-12) |
| `clientRequestId` | string |  | Retry-safe request key |
| `waitSeconds` | integer |  | How long to wait for the run to finish before returning (default 45 s) |

## `continue`

Continue a failed run: reopen its one failed node (or a stopped run's nodes) as a new attempt (an operator decision).

Scope: `operator`

| Argument | Type | Required | Description |
|---|---|---|---|
| `runId` | string | yes |  |
| `nodeId` | string |  |  |

## `delete`

Delete a finished run: without updatedAt, preview; with the preview's updatedAt, delete. Artifacts stay.

Scope: `operator`

| Argument | Type | Required | Description |
|---|---|---|---|
| `runId` | string | yes |  |
| `updatedAt` | string |  |  |

## `drain`

Drain the host before a stop or upgrade: admit no new run, and report the runs still executing. Call again to poll.

Scope: `operator`

No arguments.

## `events`

Read the event log in order (QA-7): entries after a cursor, optionally for one run, node, session, turn, or type, or since a time. Pass `next` back as afterSeq for the following page.

Scope: `operator`

| Argument | Type | Required | Description |
|---|---|---|---|
| `runId` | string |  | Only this run's entries |
| `nodeId` | string |  | Only this node's entries |
| `sessionId` | string |  | Only this session's entries |
| `turnId` | string |  | Only this provider turn's entries |
| `type` | string |  | Only entries of this type, e.g. workflow.node.failed |
| `since` | string |  | Only entries at or after this time (ISO 8601; read as UTC) |
| `afterSeq` | integer |  | The cursor: entries after this seq (default 0, the start) |
| `limit` | integer |  | Entries per page (default 100, at most 1000) |

Scope: `operator`

| Argument | Type | Required | Description |
|---|---|---|---|

## `research`

Research a question with the research profile: testable hypotheses, two cited literature reviews on two provider families (web search, or the providers' Deep research with `deep`), one evidence table from both, a critique on another family, and conclusions per hypothesis that say where the reviews agree and differ. Returns at once with a runId; poll `result` (runs take minutes; with `deep`, up to an hour).

Scope: `client`

| Argument | Type | Required | Description |
|---|---|---|---|
| `question` | string | yes |  |
| `deep` | boolean |  | Review the literature with the provider's Deep research |
| `classification` | "public" \| "operator-shared" \| "local-private" |  | Data classification of the input; local-private content never leaves the machine (INV-12) |
| `clientRequestId` | string |  | Retry-safe request key |

## `result`

Fetch a run started by `ask` or `research`; waits up to waitSeconds for it to finish.

Scope: `client`

| Argument | Type | Required | Description |
|---|---|---|---|
| `runId` | string | yes |  |
| `waitSeconds` | integer |  | How long to wait for the run to finish before returning (default 45 s) |

## `resume`

Admit new runs again after a drain.

Scope: `operator`

No arguments.

## `run`

Start a workflow template by name (built in: ask, panel; profiles add more, such as research); its steps are routed by capability to the Workers that can do them. Waits up to waitSeconds; otherwise returns a runId for `result`.

Scope: `client`

| Argument | Type | Required | Description |
|---|---|---|---|
| `template` | string | yes |  |
| `input` | string | yes |  |
| `variant` | string |  | A variant the template defines (research: deep) |
| `sessionId` | string |  | Continue an existing session |
| `persist` | boolean |  | Start a persistent session |
| `tier` | "economy" \| "standard" \| "frontier" |  | Minimum tier for the steps that take the caller's tier |
| `classification` | "public" \| "operator-shared" \| "local-private" |  | Data classification of the input; local-private content never leaves the machine (INV-12) |
| `clientRequestId` | string |  | Retry-safe request key |
| `waitSeconds` | integer |  | How long to wait for the run to finish before returning (default 45 s) |

## `status`

Health of the system harness: each check (runtime, store, disk, vault key, accounts, Workers, provider UI drift) and the worst of them, with what to do for operator callers; plus the kernel services and installed providers.

Scope: `client`

No arguments.
